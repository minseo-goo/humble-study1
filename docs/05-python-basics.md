## P-2, P-3. 삼각함수 그리기

사인 함수 `y = A · sin(2π f t) + B`

| 기호 | 의미 |
|---|---|
| A | 진폭 (앰플리튜드, 중심에서 최대까지의 거리) |
| f | 주파수 (Hz, 1초에 몇 번 출렁이는가). f=1이면 1초에 한 번, f=2면 2Hz |
| t | 시간 배열 |
| B | 바이어스 (그래프 전체를 위/아래로 이동) |

```python
import numpy as np
import matplotlib.pyplot as plt

t = np.arange(0, 6, 0.01)       # 0부터 6 미만까지 0.01 간격 → 600개 (6은 포함하지 않음)
t.shape                         # (600,)
y = np.sin(np.pi * t)           # 배열 전체에 한 번에 적용됨
y.shape                         # (600,)

plt.figure(figsize=(12, 6))
plt.plot(t, y)
plt.grid()
plt.show()
```
함수로 재사용성을 높인 버전은 `practice/notebooks/p2_p3_sine_plot.py`에 있습니다.

## P-4, P-5. 클래스 만들기

- 클래스 이름은 **첫 글자를 대문자**로(`DrawSin`), 함수와 변수는 소문자와 밑줄
- 함수는 `def 이름():`처럼 괄호가 필수이지만, 클래스는 괄호를 생략할 수 있음
- `__init__`(언더바 2개씩)은 인스턴스를 만들 때 처음 실행되는 초기화 함수
- `self`는 **인스턴스 자신**을 가리키는 변수입니다. `DrawSin(1, 1, 0, 3)`으로 만들면 `self`가 `ds`가 되고, 인자는 `self` 뒤의 것부터 매핑됩니다.
- `ds.__dict__`로 인스턴스의 변수를 딕셔너리로 확인합니다.
- 클래스는 한 번 만들어 두고 여러 인스턴스를 만들 수 있습니다.
- `__init__`에 정의한 인자를 빼먹으면 에러가 납니다.

예시는 `practice/notebooks/p4_p9_classes.py`에 있습니다.

## P-8. 메서드 오버라이딩
- 부모와 **같은 이름의 함수를 자식에서 다시 정의**하면 자식 것이 부모 것을 덮어씁니다.
- 함수 이름은 유지하면서 내용을 바꾸고 싶을 때 씁니다(예: 그래프 꾸미기 추가).

## P-9. super()
- 자식에서 `__init__`을 다시 정의하면 **부모의 `__init__`이 오버라이딩**되어 부모의 변수들이 사라집니다.
- 부모의 초기화를 유지하면서 변수를 추가하려면 `super().__init__(...)`을 호출합니다.
- ROS에서 노드를 만들 때 `class MyNode(Node)`에서 `super().__init__('node_name')`을 쓰는 것이 바로 이 패턴입니다.
